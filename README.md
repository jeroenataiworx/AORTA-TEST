# AORTA-documentatie – GitHub-export

Deze repository bevat twee representaties van dezelfde bronpackage:

- **[Website](docs/index.html)**: de statische MkDocs-website; op GitHub Pages via de Pages-URL.

De website is gebouwd uit het bestaande ResearchMaster MkDocs 1.0.6-project. De bestanden in `source/` zijn inhoudelijk ongewijzigd.
