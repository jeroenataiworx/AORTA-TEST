# Autorisatie Server MedMij (AS MedMij)

- De Autorisatie Server van MedMij ondersteunt het verkrijgen of uitgeven van een MedMij access token (toegangstoken)

- De Autorisatie Server van MedMij ondersteunt het inwisselen van een MedMij access token voor een AORTA access (JWT) token (benodigd bij de Resource Broker MedMij).

- De AORTA Token Interface is gebaseerd op [OAuth token exchange](https://tools.ietf.org/html/rfc8693).
