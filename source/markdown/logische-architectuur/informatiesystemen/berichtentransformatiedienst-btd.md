# Berichtentransformatiedienst (BTD)

De Berichtentransformatiedienst (BTD wordt via de VnC (de Verzending en Consolidatie Resource Broker) aangeroepen en transformeert HL7v3 berichten van en naar HL7-FHIR. De BTD bestaat uit een aantal endpoints. Ieder endpoint biedt een specifiek type transformatie.
