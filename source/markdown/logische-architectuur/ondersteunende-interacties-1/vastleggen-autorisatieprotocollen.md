# Vastleggen autorisatieprotocollen

Zoals beschreven op pagina '[Bevoegdheid op basis van BIG-titel](../primaire-interacties/toegangsmodel.md#bevoegdheid-op-basis-van-big-titel)' wordt een autorisatieprotocol vastgesteld waarin wordt vastgelegd per beroepsgroep en specialisatie welke berichten kunnen worden verstuurd via AORTA. Een autorisatiecommissie stelt deze autorisatieprotocollen vast en laat deze via de autorisatiemanager vastleggen door het LSP.
